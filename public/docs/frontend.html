Guide · Interface

Interface & expérience

Le front d'Agent BI est volontairement sobre : un assistant, pas un tableau de bord saturé. On suit un fil guidé ; la complexité s'ouvre à la demande.

Les écrans

  1. Landing. Présente le projet, propose Se connecter ou Créer un compte. Aucun accès au reste sans authentification (auth gate).
  2. Authentification. Email + mot de passe ; JWT stocké en localStorage ; expiration = 24 h (configurable).
  3. Accueil. Choix de la source (fichier ou SGBD) et historique des pipelines récents.
  4. Dashboard. Quatre onglets : Pipeline (live), Schémas, Analyse, Exports.
  5. Documentation. Ouvre /docs dans un nouvel onglet (ce site).

La barre latérale

La sidebar gauche condense les actions récurrentes : Accueil (retour landing), Pipeline (live), Schémas, Analyse NL→SQL, Exports, Documentation. Elle est collapsible : un clic réduit les libellés à de simples icônes.

Raccourci. Cmd/Ctrl + \\ bascule la sidebar. ? ouvre la liste des raccourcis.

Live console (SSE)

La console est bâtie autour d'un composant <StreamLog /> qui consomme le store streamLogs. Les lignes sont colorées par niveau (log, info, warn, error). Une barre de progression globale interpole entre les jalons publiés par l'orchestrateur.

// Extrait simplifié
const logs = usePipelineStore((s) => s.streamLogs);
return (
  <div className="stream-log">
    {logs.map((l) => <Line key={l.id} level={l.level} text={l.text} />)}
  </div>
);

Schémas visuels

Le diagramme du schéma en étoile est rendu en SVG : les faits sont centraux (dégradé violet), les dimensions en périphérie (cyan). Un clic sur une table affiche ses colonnes et ses types ; un menu contextuel propose Renommer, Exclure, Transformer.

Analyse en langage naturel

Dans l'onglet Analyse, tapez une question (« Chiffre d'affaires mensuel par région en 2025 »). L'agent Narrateur propose un SQL ; vous pouvez l'éditer puis l'exécuter. Les résultats sont rendus en tableau et automatiquement en graphique adapté (barre, ligne, camembert) grâce à Recharts.

Exports

Quatre formats sont disponibles :

FormatUsage
PDFRapport synthétique imprimable.
PPTXPrésentation clé en main (modèle corporate).
HTMLMicro-site autonome avec tous les KPIs.
XLSXWorkbook pour l'équipe finance.
Power BI. Un export Power BI produit un modèle .pbit avec les relations et mesures DAX, prêt à être ouvert dans Power BI Desktop.

Thème

L'UI suit un thème sombre à dominante indigo/violet avec accents cyan, inspiré des consoles développeur modernes. Les couleurs sont pilotées par variables CSS ; un thème clair est exposé via data-theme="light" sur <html>.

Accessibilité

  • Contrastes AA vérifiés sur tous les composants texte/fond.
  • Navigation clavier complète (tous les éléments interactifs sont tabindex-friendly).
  • Support du prefers-reduced-motion pour désactiver les transitions.
  • Libellés ARIA systématiques sur les boutons icônes.
